# Employee Management System - Full Stack

 Full Stack Java Developer

## Tech Stack
- Backend: Spring Boot, Spring Data JPA, REST APIs
- Frontend: React JS (Purple Themed UI)
- Database: MySQL
- Tools: Eclipse, VS Code, Git, Postman

## Features
- Add Employee
- Get All Employees
- Get Employee by ID
- Update Employee
- Delete Employee

## API Endpoints
- POST /api/employees
- GET /api/employees
- GET /api/employees/{id}
- PUT /api/employees/{id}
- DELETE /api/employees/{id}

## How to Run
Backend: Run as Spring Boot App (port 8080)
Frontend: npm start (port 3000)
